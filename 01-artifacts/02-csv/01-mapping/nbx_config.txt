#   445 SMB | 3306 MySQL | 3389 RDP | 5432 PostgreSQL | 5900 VNC

#   1900 UPnP/SSDP | 5000 UPnP | 7000 AirPlay | 8008 Google Cast
#   8009 Chromecast | 8080 HTTP-Alt | 8443 HTTPS-Alt | 8888 HTTP-Alt
#
# Drucker / NAS:
#   9100 RAW Print | 515 LPD | 631 IPP | 548 AFP | 2049 NFS
#
# Router / Switches:
#   23 Telnet | 22 SSH | 80 HTTP | 443 HTTPS | 161 SNMP
#

#   49152-49160
#
scan_ports=22,23,25,53,80,110,135,139,143,161,389,443,445,515,548,631,1900,2049,3306,3389,5000,5432,5900,7000,8008,8009,8080,8443,8888,9100,49152,49153,49154
