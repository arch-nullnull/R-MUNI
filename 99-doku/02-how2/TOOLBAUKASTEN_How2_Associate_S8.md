================================================================================
1. KURZ GESAGT: WAS IST DER TOOLBAUKASTEN?
================================================================================

Der R+MUNI Toolbaukasten ist die Sammlung von Software-Werkzeugen
die du brauchst um R+MUNI zu nutzen.

Gedacht wie ein Auto:
  → Das Auto selbst = R+MUNI (kostenlos)
  → Die Werkzeuge = Softwaretools
  → Du brauchst nur das Minimum zum Fahren

Struktur:
  MINIMUM (absolut notwendig)
    → Klein, kostenlos, reicht für Basis-Funktionen
    → Hier anfangen

  STANDARD (vollständig, empfohlen)
    → Alles was du für echten produktiven Einsatz brauchst
    → Immer noch ~95% kostenlos
    → Das ist normal

  EXTRAS (optional, wenn du brauchst)
    → Erweiterte Features für spezielle Anwendungsfälle
    → Nicht erzwungen
    → Deine Entscheidung

3. WELCHE TOOLS BRAUCHST DU KONKRET?

3.1 Das MINIMUM (absolut notwendig)
------------------------------------

ARCHI 5.8 — Das Modellierungs-Werkzeug
  Download: https://www.archimatetool.com/download/
  Kostenlos: Ja
  Was tut es: Du zeichnest deine Unternehmensarchitektur
  Aufwand: 10 Minuten Download + Installation
  Nach Installation: Ein Plugin installieren (jArchi)

CAMUNDA MODELER — Prozess-Zeichnen (optional aber sinnvoll)
  Download: https://camunda.com/download/modeler/
  Kostenlos: Ja
  Was tut es: Du zeichnest deine Geschäftsprozesse
  Aufwand: 5 Minuten Download + entpacken

PYTHON — Das Automatisierungs-Werkzeug (im Hintergrund)
  Download: https://www.python.org/
  Kostenlos: Ja
  Was tut es: Konvertiert deine Modelle automatisch
  Aufwand: 10 Minuten Installation
  (Du brauchst das nicht zu verstehen, es läuft nebenbei)

OPENJDK — Die Laufzeit (ohne dieses läuft nichts)

  Kostenlos: Ja
  Was tut es: Ermöglicht es dass Archi und andere Tools laufen

4. WARUM DIESE TOOLS? (Die Philosophie)
================================================================================

4.1 Warum Archi und nicht [anderes teures Tool]?
-----------

Wir nutzen NICHT:
  ✗ Sparx Enterprise Architect (1000+ EUR, Overkill)
  ✗ SAP Solution Manager (Zu teuer, Vendor Lock-in)
  ✗ Mega Process (Kompliziert, Overhead)

Wir nutzen ARCHI weil:
  ✓ Kostenlos und quelloffen (kann nie wegnehmen)
  ✓ Über 15 Jahre gepflegt (sehr stabil)
  ✓ Großartige Community
  ✓ Du besitzt deine Dateien (nicht locked in)
  ✓ Standard ArchiMate (nicht proprietär)
  ✓ Einfach zu bedienen (GUI, nicht CLI)

Das ist eine bewusste Entscheidung: **Langfristigkeit statt Effekt-Hascherei.**


4.2 Warum kein Microsoft Excel für alles?
---

Excel ist toll, aber:
  ✓ Archi ist besser für Architektur-Modellierung
  ✓ Prozesse in BPMN sind visuell sauberer
  ✓ CSV-Export aus Archi ist automatisierbar
  ✓ Manuelle Excel-Änderungen sind fehleranfällig

Tipp: Excel brauchst du trotzdem für Quick-Checks. Das ist ok.


4.3 Warum diese spezifischen Tool-Kombinationen?
---

Die Tools sind so gewählt dass sie zusammenpassen:

  Archi → exportiert zu CSV/XML
  ↓
  Python-Scripts → verarbeiten diese Dateien
  ↓
  Camunda → BPMN-Prozesse
  ↓
  Jira (optional) → Objektverlinkung
  ↓
  Confluence (optional) → Dokumentation

→ Jedes Tool passt in den anderen ein.
→ Keine Reibereien, keine teuren Integrations-Albträume.

5. KANN ICH ANDERE TOOLS VERWENDEN?
================================================================================

Kurze Antwort: **Es kommt drauf an.**

Das Herz von R+MUNI (Archi + Python) ist hart:
  → Das brauchst du
  → Du kannst das nicht einfach ersetzen

Die Schale um R+MUNI ist flexibel:
  → Statt Notepad++ kannst du einen anderen Editor nutzen
  → Statt GitHub Desktop kannst du Git von der Konsole nutzen
  → Statt Obsidian kannst du deine Dokumente anders navigieren
  → Statt Jira kannst du andere Ticketsysteme nutzen

Das ist Design-Intention:
  **Der Kern ist stabil, die Umgebung ist austauschbar.**

Wenn du andere Tools nutzen willst:
  → Sprich mit EUMAXL (Entwickler)
  → Erkläre ihm warum
  → Er zeigt dir wie das funktioniert

6. FIRST STEPS: WIE DU KONKRET ANFÄNGST
================================================================================

Schritt 1: Das Minimum installieren (ca. 1 Stunde)
  1. Archi 5.8 downloaden und installieren
  2. jArchi Plugin installieren (im Archi Menü)
  3. Python instalieren + pip install lxml openpyxl
  4. OpenJDK installieren
  5. Fertig

Test: Öffne Archi → neues leeres Projekt → Modell zeichnen
  → Wenn das funktioniert, hast du die Basis

Schritt 2: Erstes Modell zeichnen (ca. 2 Stunden)
  1. Ein konkretes Thema wählen
     z.B. "Meine aktuelle IT-Infrastruktur"
     z.B. "Unser wichtigster Geschäftsprozess"
  2. Nicht alles auf einmal — nur einen Bereich
  3. Ausprobieren: Elemente zeichnen, verschieben, verlinken
  4. Mit dem Modell spielen

Schritt 3: Export ausprobieren (ca. 30 Minuten)
  1. CSV-Export machen (Archi → File → Export)
  2. Die Datei mit Excel ansehen
  3. Verstehen wie die Daten strukturiert sind
  4. Ggf. im Modell anpassen, erneut exportieren

Schritt 4: Optional erweitern (spätere Schritte)
  1. Git installieren und erstes Repository erstellen
  2. Team einbeziehen (Jira optional)
  3. Automatisierung aufbauen (mit Python-Scripts)
  4. Längerfristige Strategie überlegen

→ Das geht nicht schnell. Das geht dafür langfristig.

7. HÄUFIG GESTELLTE FRAGEN
================================================================================

F: Ich nutze bereits [anderes EA-Tool]. Kann ich R+MUNI damit verbinden?
A: Technisch vielleicht ja, aber das ist Integration-Arbeit.
   Sprich mit EUMAXL. Die Basis-Funktionen sind davon unabhängig.

F: Kann ich mein Modell auch offline nutzen?
A: Ja, Archi läuft komplett lokal. Internet ist nur für optionale
   Team-Features nötig (Jira/Confluence).

F: Was passiert wenn Archi-Entwicklung stoppt?
A: Quellcode ist offen, wird nicht gelöscht.
   Aber: Archi wird seit 2008 gepflegt. Das ist sehr stabil.

F: Ich bin ein großes Unternehmen (1000+ Mitarbeiter). Passt R+MUNI?
A: R+MUNI ist für KMU bis ca. 50 User designed.
   Größer wird schwierig. Sprich mit EUMAXL über deine Anforderungen.

F: Ich möchte nicht Archi nutzen sondern [anderes Tool].
A: Das Archi-Teil ist hart. Aber drum herum ist vieles flexibel.
   Sprich mit EUMAXL was technisch möglich ist.

F: Kosten die optionalen Tools wirklich nichts?
A: Alle STANDARD-Tools sind 100% kostenlos.
   Die EXTRAS (wie Jira Pro) kosten nur wenn du viele Leute hast.

F: Wer ist EUMAXL?
A: Der Entwickler von R+MUNI. Sprich mit ihm wenn du
   Spezialfragen hast oder etwas nicht funktioniert.

F: Gibt es Support wenn was nicht funktioniert?
A: R+MUNI ist ein Community-Projekt, nicht ein Enterprise-Tool.
   Keine 24/7 Hotline, aber: Sprich mit EUMAXL, er hilft gerne.
