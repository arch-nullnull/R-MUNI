================================================================================
SCHRITT 0 – run-scope.txt VORBEREITEN
================================================================================

Datei: 03-stages/run-scope.txt

Folgendes Pair muss aktiv (uncommentiert) eingetragen sein:

  SOURCE=ATL
  MODEL=R+Muni Architecture Modell.xml

Regeln:
  - Beide Zeilen müssen direkt untereinander stehen
  - Keine Leerzeile zwischen SOURCE= und MODEL=
  - Kein führendes # (sonst inaktiv)
  - MODEL= muss exakt dem Dateinamen im child-Ordner entsprechen

ACHTUNG: Bestehende SOURCE=ARCHIMATE oder SOURCE=BPMN Einträge bleiben
unverändert — ATL liest nur SOURCE=ATL, andere Flows ignorieren ihn.

================================================================================
SCHRITT 4 – JIRA CSV-IMPORT DURCHFÜHREN
================================================================================

1. Jira öffnen → dein Projekt wählen

2. Im Projekt-Menü:
   Project Settings → Import → CSV

3. Datei hochladen:
   03-stages/00-archimatearchive/jira_ea_import.csv

4. Feld-Mapping in Jira UI prüfen:
   Summary      → Summary        (Pflicht — muss gemappt sein)
   Issue Type   → Issue Type     (Pflicht — muss gemappt sein)
   Description  → Description
   Labels       → Labels
   Priority     → Priority       (leer = Medium, kann ignoriert werden)
   EA-ObjectKey → [ignorieren oder Custom Field]
   EA-ArchiType → [ignorieren oder Custom Field]
   EA-Group     → [ignorieren oder Custom Field]
   EA-SourceModel → [ignorieren oder Custom Field]

5. Import starten → Jira erzeugt Issues für alle EA-Objekte

ACHTUNG: Beim zweiten Import entstehen Duplikate.
Empfehlung: Vor erneutem Import die EA-Issues in Jira löschen
(Filter: labels = EA_Object oder Issue Type = Task + Label-Filter).


================================================================================
SCHRITT 5 – CONFLUENCE JIRA-ISSUES-MAKRO EINRICHTEN
================================================================================

Voraussetzung: Schritt 4 (Jira-Import) abgeschlossen.

1. Confluence Seite öffnen (oder neue Seite anlegen)
   Empfehlung: Eine Seite pro Gruppe oder eine Übersichtsseite

2. Seite bearbeiten → + (Einfügen) → Makro suchen → "Jira Issues"

3. Im Makro-Dialog:
   Verbindung: dein Atlassian Site wählen
   JQL-Filter eingeben, z.B.:

   Alle EA-Objekte:
     project = "DEIN-PROJEKT" AND issuetype = Task AND labels in
     (ApplicationComponent, BusinessProcess, BusinessActor, Node,
      Goal, Equipment, DataObject)

   Nur Applikationen:
     labels = ApplicationComponent

   Nur Prozesse:
     labels = BusinessProcess OR labels = ApplicationProcess

   Nur Akteure:
     labels = BusinessActor OR labels = BusinessRole OR labels = Stakeholder

   Nur Technologie:
     labels = Node OR labels = Device OR labels = SystemSoftware

   Nur Motivation:
     labels = Goal OR labels = Requirement OR labels = Principle

4. Spalten konfigurieren (empfohlen):
   Summary, Labels, Description

5. Speichern → Confluence zeigt die EA-Objekte als live Tabelle

Vorteil: Ändert sich ein EA-Objekt in Jira, aktualisiert sich
die Confluence-Seite automatisch ohne erneuten Script-Lauf.
